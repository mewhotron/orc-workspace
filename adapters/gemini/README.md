# Gemini CLI adapter

The overlay adds a project GEMINI.md that points to the canonical core instructions. No experimental features, global settings, model names or account credentials are installed.

This is an instruction adapter, not a claimed native multi-agent implementation. Inspect the host's actual tools; use native delegation only if present and verified, otherwise manual handoff or a disclosed single-assistant workflow. A new session can inspect its loaded context with the host's current memory controls.

Format reviewed against [official GEMINI.md guidance](https://geminicli.com/docs/cli/gemini-md/). Live execution on Gemini CLI is unverified in this release.
