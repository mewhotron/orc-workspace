# Claude Code adapter

The overlay adds CLAUDE.md and selected pack role files under .claude/agents. The entrypoint tells the host to read canonical core instructions. Coaching specialist definitions allow only reading/searching local files; implementation roles rely on normal host approvals. No model or permission-bypass setting is installed.

Open a fresh session in the destination and verify loaded project instructions and available agents using the host's current controls. Execute a harmless handoff before marking delegation verified. This release does not assert live Claude Code execution merely because the adapter format is valid.
