# Capability inventory for 0.1.0

This release preserves reusable coordination and selected local tools. It is not a byte-for-byte copy of private source projects or complete runtime parity with all of their integrations.

| Capability | Distribution status |
| --- | --- |
| Orc coordination, assignment IDs, model tiers, owner records | Included as provider-neutral instructions and deterministic correlation checker |
| Lead Coach and three specialists | Included as canonical roles; actual specialist consultation depends on host support |
| Knowledge Curator | Included role and local ingestion/provenance workflow |
| Local knowledge import/search/citations | Included provider-neutral SQLite tools and synthetic starter; read-only adapter for supported legacy collections |
| Original book-knowledge SQLite content | Requested but not included: substantive source-derived text; sharing basis unresolved; no original books included |
| Search Crawler research | Included role; host web/browser required; record helper and synthetic checks included |
| Media catalogue, hashes, probes, supported cuts and render validation | Included Python source and tests; external FFmpeg/FFprobe required |
| Local athlete/FIT/history/report utilities | See coaching README for the exact audited optional subset and dependencies |
| Original semantic embeddings and automated multi-stage claim/presentation verification | Not equivalent in this release; original provider-bound services are not shipped as universal features |
| Arbitrary PDF/EPUB extraction, OCR, book-specific recipe parsing | Not claimed by the generic text import route; source-specific extraction needs review/tools |
| Garmin account sync/wellness scheduling, calendar and Notion accounts | Setup recipes only; no sessions, schedules or live connection inherited |
| Original Streamlit dashboard and Discord adapter | Not bundled or enabled; independent source-project work remains unchanged |
| Navigator | Source scope was a future design; no implemented capability to export |
| Installed vendor plugins/skills | Not copied; owners obtain their own tools under applicable terms |

Do not describe lexical evidence lookup as the original verified RAG pipeline. Host-led instructions require source inspection, supported claims and abstention; they do not provide the same software-enforced validation. Generated starter data is for functional tests, not training prescriptions or literature coverage.
