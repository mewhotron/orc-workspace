# Any instruction-following AI host

Open the installed folder and ask the assistant to read AGENTS.md and its linked core files. If the host cannot access files, attach only the necessary reusable instructions; perform local commands yourself. Do not upload private records by default.

Inspect actual tools before promising browsing, subagents, account connections or filesystem edits. With no native subagent support, use a manual handoff to another user-managed session, or disclose a single-assistant workflow. Required independent consultation cannot be replaced by invented role replies.

No provider API compatibility assumption is made. Map available models in local/preferences.md; use the current host model if explicit selection is unsupported. Ask the host to report the files it actually read and run a harmless ID-matched delegation probe before marking coordination verified.
